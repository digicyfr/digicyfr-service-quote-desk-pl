# Security

Report a suspected vulnerability privately through [GitHub's security advisory form](https://github.com/digicyfr/digicyfr-service-quote-desk-pl/security/advisories/new) or email security@digicyfr.com. Include the plugin version, WordPress/PHP versions, reproduction steps and impact. Do not include real customer data in a public issue. The latest tagged release is supported; no fixed response time is promised.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/digicyfr/digicyfr-service-quote-desk-pl/issues). The plugin sends no telemetry or automatic vulnerability reports.
